# AutoHub — Car Listing Platform (Demo)

An AutoScout24-style car listing platform demo.

- **Listing page** (`demo/index.html`) — instant AJAX-style filtering by make, model, year, price, mileage, fuel, gearbox and body; card image carousels; sorting and pagination. Handles a large inventory smoothly.
- **Admin** (`demo/admin.html`) — the fast <2-minute add-a-car flow: basic specs, one-tap options, drag-and-drop photos, publish.

This is a front-end demo. The production build uses Next.js + a lightweight backend/DB with server-side filtering and indexing to stay fast across thousands of listings.
